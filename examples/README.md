# Examples

This directory will contain real, representative inputs (public GitHub
issues/pull requests) and the actual generated outputs produced by Clueberry
once the investigation pipeline exists.

No examples are included yet. Clueberry's analysis functionality
(GitHub ingestion, repository inspection, claim extraction, evidence
collection, verdict generation) has not been implemented — only the project
foundation (CLI skeleton, configuration, packaging, CI) exists at this stage.

Examples added in later sprints will be genuine, generated outputs. Nothing
here will be fabricated.
